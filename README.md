# What Makes a Book Loved by Readers?
Exploratory data analysis of Goodreads books and ratings to investigate book popularity and reader preferences.

## Project Overview

This project explores a dataset of books and user ratings from Goodreads to investigate the factors associated with book popularity and readers' appreciation.

The main objective is to understand how different book characteristics, such as authors, publication years and genres, are related to their popularity and average ratings.

## Research Questions

The analysis focuses on the following key questions:
- Is there a relationship between the number of ratings a book receives and its average rating?
- Do some genres tend to receive higher ratings than others?
- Do older and more recent books differ in terms of average ratings and popularity?
- How do average ratings vary across the works of different authors?

## Dataset

The project uses the [goodbooks-10k dataset](https://github.com/zygmuntz/goodbooks-10k).
The dataset contains approximately 10,000 books and 6 million user ratings.


## Interactive Streamlit Application

An interactive web application was developed using Streamlit and Plotly to explore how readers' rating distributions differ across books.

Users can search for a book by title or author, view its average rating, and explore the percentage of 1-star to 5-star ratings through an interactive bar chart.
